## Student Expense Tracker

A simple, interactive web application designed to help students manage their personal finances by tracking income and expenses. Built with **HTML, CSS, and JavaScript**, the application allows users to record transactions, categorise expenses, monitor their available balance, and view their transaction history.

**Key Features**

* Track income and expenses in real time
* Categorise expenses such as food, transport, data and airtime, school, and shopping
* View total income, total expenses, and current balance
* Search and filter transaction history
* Delete individual transactions or clear all records
* Save transactions using browser local storage, so data remains available after refreshing the page
* Validate inputs and prevent expenses that exceed the available balance

**Technologies:** HTML5, CSS3, JavaScript, Local Storage
